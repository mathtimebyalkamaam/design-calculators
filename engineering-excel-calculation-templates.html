Frequently Asked Questions

Are these calculation templates compatible with Microsoft Excel and Google Sheets?

Yes. All calculation sheets are formatted in RFC 4180 compliant CSV format embedded with a UTF-8 Byte Order Mark (BOM). They open directly in Microsoft Excel (all versions), Google Sheets, Apple Numbers, and LibreOffice without manual delimiter configuration or character distortion.

Which engineering standards govern these calculation templates?

Every sheet directly references recognized industry design codes, including IEEE 1584-2018 (Arc Flash), IEEE 80-2013 (Grounding), IEC 60364-5-52 (Cable Sizing), IEC 60534 (Control Valves), API 520/526 (Pressure Relief Valves), and ASME Section VIII Div 1.

Can I attach these exported spreadsheets to formal client design submittals?

Yes. Each sheet includes standard project metadata blocks containing document title, reference standard, review timestamps, input variables with units, and verified output metrics. They are engineered to accompany design packages, permit applications, and QA/QC audit files.

How do web calculators compare with standalone Excel spreadsheets?

Our online calculators allow instant interactive sensitivity analysis and automatic parameter verification. Once your calculation is finalized, you can export the data directly into an Excel/CSV spreadsheet for archival, client handover, or further custom numerical processing.
